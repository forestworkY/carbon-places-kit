# Carbon Places Kit — Project Concept

Concept materials for **Carbon Places Kit** (October 2026).

- `Carbon_Places_Kit_Concept.pdf` — GitHub-friendly preview of the project concept deck.
- `Carbon_Places_Kit_Concept.pptx` — editable PowerPoint source.

The concept positions Carbon Places Kit as reusable infrastructure for place-based carbon and ecosystem information, with an emphasis on understandable, reusable, and traceable local information.
